## 二、推荐学习路线

### 路线 A：纯新手（先懂"游戏怎么跑起来"）

```
学习指南
  → 第 1 课（游戏循环）
  → 第 2 课（输入）
  → 第 3 课（事件）
  → Player 第 1 课
  → 第 4 课（功能设计）
  → GameManager 讲解
  → 武器系统讲解
```

### 路线 B：想改枪 / 做武器

```
学习指南
  → 武器系统讲解（先通读，别纠结细节）
  → 第 1 课（循环，看武器的 OnUpdate/OnControl）
  → 第 2 课（输入，看武器怎么响应按键）
  → 回头精读武器系统讲解的"新增实践"一节
```

### 路线 C：想理解"功能怎么设计"

```
第 3 课（事件）
  → 第 4 课（功能设计实战）
  → GameManager 讲解（看一个完整系统怎么组织）
  → 挑一个你感兴趣的功能（座位 / 载具 / NPC），搜它发的事件和它的基类
```

## 三、推荐继续整理的文档

下面这些是**还没有写**、但对学习很有价值的方向，按推荐度排序：

| 优先级 | 文档 | 为什么推荐 |
|---|---|---|
| 高 | 相机系统（第一/第三人称、视角、射击准星） | 独立完整、几乎每个功能都会碰 |
| 高 | 物理与射线检测（`Scene.Trace`、碰撞、布娃娃） | 游戏开发基础，枪、近战、工具都靠它 |
| 中 | 伤害与死亡（`DamageInfo`、`IDamageable`、事件链） | 把 Player、武器、NPC 串起来 |
| 中 | 座位与载具（`ISitTarget`、`IPlayerControllable`、驾驶） | 项目里很典型、能练"接口 + 组件" |
| 中 | HUD / UI（Razor 组件、`Painter`、提示） | 做功能绕不开界面 |
| 中 | 存档系统（`Global.ISaveEvents`、`LocalData`、存档位） | 理解"数据怎么存下来" |
| 中 | NPC 基础（感知、`TickSchedule`、`NpcSystem`） | 看 AI 状态机怎么写 |
| 低 | 网络进阶（`[Sync]`、`[Rpc]`、`IsProxy`、预测） | 重要但难，建议最后学 |
| 低 | 性能与优化（对象池、`OnUpdate` 开销、Tick 分配） | 等能写功能了再看 |
| 低 | 音效系统（`PlaySound`、事件、3D 音效） | 相对独立，随时能补 |

## 四、看文档的小提示

- 文档里的代码都**来自项目源码**，路径写成 `../Code/...` 的点一下就能跳过去对照。
- 涉及引擎内部机制的地方，文档会写"以引擎版本为准"——因为引擎源码不在这个仓库里。
- 网络相关的内容（`[Sync]`、`[Rpc]`、`IsProxy`）都**故意放在每份文档的最后**，新手可以先跳过。
- 建议配合"打开源码对照着看"：文档里出现的每个类名，都能在 `Code/` 下搜到。
